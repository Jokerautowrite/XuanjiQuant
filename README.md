# XuanjiQuant 本地自进化智能量化交易系统

## 项目简介

本项目依托腾讯金融官方API，搭建本地化专属量化数据库，全程本地运行、无云端泄露、无第三方依赖，深度融合GitHub全球顶级量化项目核心算法与量化公式，实现璇玑智能体自主开智、全自动运行。

无需人工干预，每日同步大盘行情、自动复盘、多维度全周期优化量化指标，自主迭代进化交易策略。

## 核心定位

- **本地化部署**：腾讯金融API构建独立量化数据库
- **自主开智进化**：Claw智能体自动运算，无需人工调参
- **顶级算法融合**：标准化量化公式，多因子多周期策略
- **防虚假防错误**：全周期盲测，强弱个股双向验证
- **全自动闭环**：每日自动同步、复盘、调参、进化

## 核心公式

### 全局总控进化母公式

$$\Delta Q = \frac{C_{tick} \cdot \Lambda_{gene} \cdot \Omega_{market}}{H_{noise} \cdot T_{cycle}} \cdot \eta_{evo} \cdot \sigma_{valid}$$

### 因子标准化公式

$$F_{std} = \frac{F_{raw} - \mu_{period}}{\sigma_{period}} \cdot \rho_{market}$$

### 多因子信号合成公式

$$S_{signal} = \alpha_1 T_{trend} + \alpha_2 F_{fund} + \alpha_3 M_{flow} + \alpha_4 V_{vol}$$

### 多周期趋势共振公式

$$R_{resonate} = T_{short} \cap T_{mid} \cap T_{long}$$
