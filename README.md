# XuanjiQuant 本地自进化智能量化交易系统

## 核心定位

本项目依托腾讯金融官方API，搭建本地化专属量化数据库，全程本地运行、无云端泄露、无第三方依赖，深度融合**神经-模型对齐**核心算法，实现璇玑智能体自主开智、全自动运行。

## 主公式（核心损失函数）

$$L_{total} = \alpha \cdot L_{class} + (1-\alpha) \cdot L_{neural}$$

### 子公式

**分类损失：**
$$L_{class} = CrossEntropy(y_{pred}, y_{true})$$

**神经对齐损失：**
$$L_{neural} = MSE(f_{model}(x), f_{brain}(x))$$

### 关键参数

| 符号 | 含义 |
|------|------|
| α | 平衡系数（控制分类与神经对齐权重） |
| f_model(x) | 模型多层特征提取 |
| f_brain(x) | 人脑EEG/fMRI神经表征 |
| 目标 | 联合优化，提升模型–大脑表征相似性 |

## 核心功能

1. **本地量化数据库**：腾讯金融API构建独立量化数据库
2. **神经-模型对齐**：核心算法驱动的量化策略优化
3. **全自动闭环**：每日自动同步、复盘、调参、进化
4. **防虚假验证**：全周期盲测，强弱个股双向校验

## 适用场景

- 个人量化交易者，本地化私有化策略研发
- 无编程基础，纯公式化智能量化运行
- 全天候自动运行，无需实时盯盘
